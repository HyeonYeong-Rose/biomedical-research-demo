## 추천 논문

### 1. Anatomy-Structured Hierarchical MIL for Weakly-Supervised Thoracic Disease Detection in Chest X-rays
[arXiv](https://arxiv.org/abs/2609.33520v1) · MICCAI · 축: 기관 간 일반화, 롱테일 라벨 분포
- **왜 관련 있나**: 해부학 사전 정보를 쓰는 약지도 병변 검출로, CXR8 형식 라벨과 맞습니다.
- **우리 데이터 근거**: 이상 127건, 다중 라벨 50건, 결절 12건.
- **알 수 없는 것**: 병변 위치 주석이 없어 위치 추정은 검증 불가.

### 2. CXR-LT 2026 challenge: Multi-center long-tailed and zero shot chest X-ray classification
[DOI](https://doi.org/10.1016/j.media.2026.104340) · Medical Image Analysis · 축: 기관 간 일반화, 롱테일 라벨 분포
- **왜 관련 있나**: 다기관·롱테일 분류 문제를 직접 다룹니다.
- **우리 데이터 근거**: 5개 기관, 정상 53.3%, 희귀 소견(폐렴 3, 종괴 2, 탈장 2).
- **알 수 없는 것**: 초록이 없어 결과는 본문 확인 필요; 희귀 소견 표본이 너무 작음.

### 3. Learning to Defer with Guidance on Real World Medical Data
[arXiv](https://arxiv.org/abs/2609.26384v1) · MICCAI · 축: 판독자 협업
- **왜 관련 있나**: AI가 판독자에게 사례를 넘기는 전략을 실제 판독자 주석 데이터로 평가합니다.
- **우리 데이터 근거**: AP 88건(32.4%) 등 촬영 조건 혼재, 이상 비율 46.7%.
- **알 수 없는 것**: 다중 판독자 주석이 없어 위임 이득은 검증 불가.

### 4. Physician involvement and research quality in chest X-ray foundation models
[DOI](https://doi.org/10.1038/s41746-026-03205-0) · npj Digital Medicine · 축: 보고 품질
- **왜 관련 있나**: 체계적 검토이며 CLAIM 준수·공정성 보고 기준을 제공합니다.
- **우리 데이터 근거**: 성별 균형(136/136), 5개 기관, 폭넓은 연령.
- **알 수 없는 것**: 모델 성능은 다루지 않으며, 합성 데이터라 공정성 평가를 대신하지 못함.
